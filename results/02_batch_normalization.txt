--------------------------------------------------
Why Batch Normalization?
--------------------------------------------------

Batch Normalization was added after each convolutional layer to normalize the activations and help stabilize neural network training.

The architecture uses:

Conv → BatchNorm → ReLU → MaxPool

for each convolutional block.

--------------------------------------------------
Why Adaptive Average Pooling?
--------------------------------------------------

The original CNN used:

Linear(128 * 28 * 28, 256)

after the convolutional layers.

With Batch Normalization, Adaptive Average Pooling was used before the fully connected layers:

AdaptiveAvgPool2d((1,1))
→ Flatten
→ Linear(128, 256)
→ ReLU
→ Linear(256, 4)

This converts the 128 feature maps into a fixed 128 × 1 × 1 representation.

Therefore, the classifier receives only 128 features instead of 128 × 28 × 28 = 100,352 features.

This greatly reduces the number of parameters in the fully connected layer and makes the classifier less dependent on the spatial dimensions of the feature maps.

--------------------------------------------------
Experiments / Changes Tried
--------------------------------------------------

1. Batch Size

The initial experiment used batch size 16.

A separate experiment was performed with batch size 32 to check whether increasing the batch size would make the BatchNorm statistics more stable.

The batch-size-32 experiment remained unstable, so the original batch size of 16 was retained.

2. BatchNorm Momentum

The default BatchNorm momentum of 0.1 was used initially.

A separate experiment was also attempted with:

BatchNorm momentum = 0.01

The lower momentum did not resolve the validation instability,
so the default momentum of 0.1 was retained.

--------------------------------------------------
Conclusion
--------------------------------------------------

Batch Normalization did not improve the baseline CNN in this configuration.

Training accuracy increased from 57.71% in the first epoch to 76.00% in the final epoch. However, validation accuracy remained highly unstable throughout training, ranging from 24.53% to 42.63%.

The validation loss also remained highly unstable, reaching values as high as 13.7189 during training.

The final model achieved a test accuracy of 35.03% and a macro F1-score of 0.1297.

The classification report shows that the model predicted only the Very Mild Impairment class for the test set. It achieved a recall of 1.00 for this class but failed to correctly identify the other three classes.

The additional experiments with batch size 32 and a lower BatchNorm momentum of 0.01 did not resolve the observed validation instability. Therefore, the original configuration with batch size 16, BatchNorm momentum 0.1, and learning rate 0.001 was retained as the final Batch Normalization experiment.

Overall, this experiment shows that adding Batch Normalization to the CNN architecture did not improve performance under the tested configuration.
