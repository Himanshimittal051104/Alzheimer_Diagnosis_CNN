- Learning Rate: 0.001
- Loss Function: CrossEntropyLoss
- Input Size: 224 x 224
- Number of Classes: 4
- Data Augmentations: Random Rotation (10 degrees), Random Horizontal Flip
- Final Transformation Order: Rotation -> Horizontal Flip

--------------------------------------------------
Why Data Augmentation?
--------------------------------------------------
The baseline CNN achieved high performance on the training data. Data augmentation was introduced to expose the model to different variations of the training MRI images and help it learn features that are less dependent on the exact appearance of individual training images.

In this experiment, Random Rotation and Random Horizontal Flip were applied to the training images. These transformations were used to create variations of the original MRI images while preserving their class labels.

The augmentation transformations were applied only to the training data. Validation and test images were kept unchanged so that model performance could be evaluated on the original data distribution.

--------------------------------------------------
Conclusion
--------------------------------------------------

The Data Augmentation model achieved a test accuracy of 80.45% and a macro F1-score of 0.8544. The model successfully learned from the augmented training data, reaching 94.03% training accuracy and 90.65% validation accuracy at its best validation epoch.

Compared with the baseline CNN, the overall test performance was lower. Therefore, for this dataset and augmentation configuration, data augmentation did not improve the overall test performance, although it provided a useful experiment for studying the effect of input transformations on model generalization.
