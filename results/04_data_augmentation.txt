Experiment 4: Data Augmentation
==================================================

Model:
CNN with Data Augmentation

Training Configuration:
- Epochs: 10
- Batch Size: 16
- Optimizer: Adam
- Learning Rate: 0.001
- Loss Function: CrossEntropyLoss
- Input Size: 224 x 224
- Number of Classes: 4
- Data Augmentations: Random Rotation (10 degrees), Random Horizontal Flip
- Final Transformation Order: Rotation -> Horizontal Flip

--------------------------------------------------
Why Data Augmentation?
--------------------------------------------------

The baseline CNN achieved high performance on the training data. Data augmentation was introduced to expose the model to different variations of the training MRI images and help it learn features that are less dependent on the exact appearance of individual training images.

In this experiment, Random Rotation and Random Horizontal Flip were applied to the training images. These transformations were used to create variations of the original MRI images while preserving their class labels.

The augmentation transformations were applied only to the training data. Validation and test images were kept unchanged so that model performance could be evaluated on the original data distribution.

--------------------------------------------------
Conclusion
--------------------------------------------------

The Data Augmentation model achieved a test accuracy of 60.44% and a macro F1-score of 0.6061.

The model showed steady improvement during training, with training accuracy increasing from 46.23% in the first epoch to 79.16% in the final epoch. Validation accuracy also improved from 62.51% in the first epoch to 79.82% in the final epoch.

The classification report shows that the Moderate Impairment class achieved an F1-score of 0.71. No Impairment achieved an F1-score of 0.69, Very Mild Impairment achieved an F1-score of 0.56, and Mild Impairment achieved an F1-score of 0.47.

Compared with the baseline CNN, which achieved 96.17% test accuracy, this data augmentation configuration resulted in substantially lower test performance. Therefore, the selected augmentation transformations did not improve the overall performance on this dataset.

Overall, this experiment demonstrates that data augmentation can significantly affect CNN performance, and the choice and order of transformations are important for Alzheimer MRI classification.
